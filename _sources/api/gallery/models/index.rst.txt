Building, Bridging and Saving Models
------------------------------------

Tools that make realistic models easy to build and move around: Bloch
Hamiltonians set up by neighbour order (1st, 2nd, 3rd, ... neighbours) as
in real space, bridges between the real-space :class:`~tbkit.system.System`
and the reciprocal-space :class:`~tbkit.kspace.KSpace` pipelines, k·p
(continuum) Hamiltonians discretized into lattice models, models
saved to and loaded from disk, tight-binding models imported from
Wannier90's ``_hr.dat`` files, and Wannier functions built from any model
(isolated or entangled bands), with their Wannier-interpolated model.
